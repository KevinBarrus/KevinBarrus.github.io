- 神经网络：类似大脑结构，有哪些区域、怎么连接
- 权重：神经元之间突触的连接强度
- 训练：不断调整这些连接强度，让模型预测越来越准
- 推理：连接强度固定下来，输入信号沿着网络传一遍，得到输出

权重是训练出来的。大致流程：随机初始化 → 给模型文本，让它预测下一个 token → 比较预测和真实答案，算损失 → 反向传播，算每个权重对错误的责任 → 用梯度下降微调每个权重 → 重复n次

神经网络在数学上可以看成一个函数，推理则是完成：得到输入 → 喂给神经网络 → 得到输出 这个过程。

当我们在网页端给 ChatGPT 发消息，消息先到 OpenAI 的前端/API 服务器，经过认证、限流、安全审核、上下文构造，加入系统提示和历史消息，然后 tokenizer 切成 token，进入推理服务。推理服务已经加载好模型权重，在 GPU 集群上做前向计算，逐 token 生成，再经过后处理和安全过滤，流式返回给浏览器。

至于本地部署，实际上是下载模型权重文件、配置文件等，再安装推理引擎，在本地的 GPU/CPU 上跑。

推理引擎的角色，让我想起了 MySQL。MySQL 让你写一句 SELECT，背后要解析、优化、执行，底层要处理索引、锁、MVCC、事务这些事情。

推理引擎类似，对外暴露简单的接口和能力，内部隐藏大量复杂工作，包括：调度与批处理、KV Cache 与显存管理、计算优化、分布式并行等。
